## Accurate preview for modded content

The preview now replays the game's real Play Hand flow in a sandbox and reads the score the game itself computes, so modded jokers, cards, enhancements, seals, editions, consumables and boss blinds preview the same as they play. No per-mod support code is needed, so new mods and new versions work automatically.

### What is new
- Accurate mode (on by default): runs the real scoring code with animations, sounds, saving and unlocks switched off, then restores the game state exactly. A fingerprint check after every run switches the engine off for the session if state is ever not restored.
- Automatic fallback to the original engine if a simulated play fails, with a short cooldown after repeated failures.
- Scoring done in coroutines (Talisman, balatro-utils async scoring) and custom event managers are handled.
- Min/max preview is computed by re-running the sandbox with every random roll forced to its extremes.
- Optional accuracy log (DVPreview_audit.log in the Balatro save folder) that compares the previewed score with the actual score after each hand.
- Two new settings toggles: Accurate Mode, and Log Preview Accuracy.

### Install
Unzip into `%AppData%\Balatro\Mods` so you have `Mods\Balatro-Preview\metadata.json`. Requires Steamodded and Lovely.

### Verification note
Automated tests of the engine against a mock of the game's event system pass (score, money, exact state restore, failure fallback, coroutine scoring, custom managers, leaked hooks). Please report any mod that still previews wrongly, with the audit log lines.
